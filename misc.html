UI-Kit

Nspire UI-Kit is a GUI framework written in python to develop GUI applications on the TI-Nspire in python

Brick Rigs Command Engine

Brick Rigs Command Engine (BRCE) is a mod for Brick Rigs written in C++ that adds chat command functionality to Brick Rigs.

BR-SDK

BR-SDK is a library written to aid in the development of mods for Brick Rigs using C++. Used by BRCE.

Sig-Gen

Sig-Gen is a signature generator for IDA-Pro to speed up time spent reverse engineering programs and libraries.

Injector-Lib

Injector-Lib is a static library for injecting DLL (Dynamic Link Libraries) into other applications on windows.
