Brick Rigs Command Engine

The Brick Rigs Command Engine(BRCE) is a mod for Brick Rigs that adds chat-commands to your Brick Rigs server. BRCE also adds moderation features to Brick Rigs through chat commands.

Download today!

How to download

Follow the video tutorial and use the links in the description and comment to download the Brick Rigs Command Engine

Download Injector

Download the injector for a plug and play experience. Just download the injector and run it.

If the injector is flagged by Windows Defender or other antivirus software, it is a false positive. You may safely allow or whitelist the file to proceed with its execution.

Download DLL

Download the standalone dll if you want to use your own dll injector or have another preference.

If the dll is flagged by Windows Defender or other antivirus software, it is a false positive. You may safely allow or whitelist the file to proceed with its execution.
